# Windows OSD

Copied from Omarchy's `omarchy.osd` panel (MIT licensed, Omarchy
contributors) and restyled as a Windows 10 dark on-screen display: `#1f1f1f`
card, white text, blue progress bar and top-left placement. The `osd` IPC
target is retained, so volume and brightness commands continue to work.
