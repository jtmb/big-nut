# Windows notifications

Copied from Omarchy's `omarchy.notifications` service (MIT licensed, Omarchy
contributors) and styled for Windows 10:

- toasts are anchored bottom-right above the taskbar
- the card has an app-name header, dark background and white text
- the `notifications` IPC target and the notification/history store are
  unchanged, so the action center keeps working
