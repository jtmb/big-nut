macOS 27 Golden Gate-inspired Omarchy theme. Uses the official macOS 27 light
wallpaper shared for download by Basic Apple Guy:
https://basicappleguy.com/haberdashery/macosgoldengate

For the paired dark appearance, use `omarchy theme set macos-2027-golden-gate-dark`.
Return here with `omarchy theme set macos-2027-golden-gate`.

The shell palette, blue menu selections, translucent menu bar, frosted
panels, calendar/weather desktop widgets, and dock resemble the 512 Pixels Golden Gate desktop
and Finder menu screenshots:
https://512pixels.net/projects/aqua-screenshot-library/macos-27-golden-gate/

The workspace buttons in the top bar switch desktops. Settings opens a single
window with Appearance, Desktop & Dock, Wallpaper, and Workspaces pages for theme, wallpaper, workspace,
window-transparency, and dock controls. App windows
are gently translucent, including those on floating workspaces; Omarchy's
Opaque window mode turns that off. The dock is also available on desktop 1
without changing its scrolling layout.

View > Change Wallpaper selects from the original wallpaper, Cool Mist, and
Rose. The latter two are recolors of the same Golden Gate artwork, not
additional official Apple wallpapers. View > Next Wallpaper cycles them.
The Dock page sets icon size (Small/Medium/Large/Default), screen edge and auto-hide.
The light appearance has its own dock-outline preference. In dark mode, Settings >
Appearance > Dark theme outlines links outlines on windows, the dock, custom
widgets, menus, and standard shell panels; it starts off. Dock choices are
preserved when switching between themes.

Settings > Appearance > Frosted Glass adds a more transparent, blurred appearance while
keeping terminal backgrounds independently see-through. Regular
transparency restores the subtler look. These use Omarchy's standard global
window-transparency mode, so the selected mode also affects other themes.

Not affiliated with or endorsed by Apple. Native macOS Finder/Safari menus
cannot be replicated by a Linux window manager; the bar menus open working
Linux actions instead. Existing Linux keyboard shortcuts remain unchanged.
Click the calendar for Omarchy's calendar, the weather card for the forecast,
or the purple image for wallpaper settings.
The weather widget calls the user's existing
`omarchy weather status` command every 15 minutes to display their configured
location's current temperature.
