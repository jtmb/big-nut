Dark companion to macos-2027-golden-gate. Uses the matching Golden Gate dark
wallpaper shared by Basic Apple Guy:
https://basicappleguy.com/haberdashery/macosgoldengate

Switch with `omarchy theme set macos-2027-golden-gate-dark` and return to
light with `omarchy theme set macos-2027-golden-gate`. Switching to any other
theme restores your prior bar, dock, and OpenCode theme settings.

The Finder-inspired menus run Linux actions, not native macOS applications.
Click the calendar for Omarchy's calendar, the weather card for its forecast,
or the purple image for wallpaper settings.
The top bar also has clickable workspaces and a unified Settings window for layout,
transparency, dock and display controls. Its Displays page follows macOS's pane:
display identity, Larger Text/Default/More Space resolution presets,
Omarchy's scale presets and text size, brightness, Night Shift, and mirroring
when an external display is connected;
unsupported macOS-only rows are omitted. Workspaces use Omarchy's default dwindle layout
while the dock is shown. Super+M or Window > Minimize sends the focused window
to the dock on tiled and floating workspaces, and its dock icon brings it back.
OpenCode opens with its session sidebar hidden so the
transcript uses the full window; `/update` updates OpenCode through mise. App windows are translucent unless Opaque mode is selected.
View > Change Wallpaper offers the original dark wallpaper, Blue Hour, and
Violet Night. Blue Hour and Violet Night are recolors of the original, not
official variants. View > Next Wallpaper cycles them. The Dock page lets you
resize icons, move the dock to any screen edge, and change auto-hide. Dark
theme outlines are linked across windows, dock, widgets and shell surfaces;
they are off by default and can be toggled in Appearance or Desktop & Dock.
Settings > Appearance > Menu Bar > Peanut logo replaces the Apple mark with a
monochrome peanut shell in the bar's foreground color; it is off by default and
follows you between the light and dark appearances.
Settings > Appearance > Frosted Glass makes windows more translucent; Regular transparency
returns to the subtler treatment. This choice uses Omarchy's global window
transparency setting and follows you to other themes.
